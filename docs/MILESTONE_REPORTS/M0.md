# Milestone Completion Report

**Milestone:** M0 — Foundation, project shell, and baseline verification
**Gate decision:** **PASS (2026-11-18).** Unit, integration and UI tests pass, and manual checklist items 1–5 were observed on a real Mac by the product owner. KI-001 is resolved.
**Branch / commit:** `milestone/M0-foundation`, merged into `main` (specs committed separately on `main` at `80bee16`)

## Implemented
- Menu-bar app (`LSUIElement`, no Dock icon, no main window). Capture, Quick Copy, Record and Library are listed but disabled as "Coming Soon".
- Settings window (AppKit `NSWindow` hosting SwiftUI, owned by `WindowCoordinator`) with six panes: Providers, OCR, Shortcuts, Storage, Capture & Recording, Privacy. OCR level, overlay dimming, recording target, cloud-consent policy and the Quick Copy history toggle are real persisted settings. Everything else is a labeled skeleton.
- Permission UI for Screen Recording and Microphone with four states (not requested, granted, denied, restricted). Reading status never prompts; requests happen only on a button click.
- Core: typed IDs, `CaptureMode`, display geometry (AppKit vs CoreGraphics points, backing pixels, normalized rects, negative origins), `AppSettings`, `AppError`, redacting diagnostics.
- Atomic JSON settings store; a corrupt or newer-version file is backed up, not overwritten. A change is shown as applied only after the save succeeds.
- Build configuration: Swift 6 language mode, complete strict concurrency, warnings as errors, macOS 27.0 target (D-010), hardened runtime in Release.
- Scripts: `build.sh`, `test.sh`, `run.sh`, `generate_project.rb`.
