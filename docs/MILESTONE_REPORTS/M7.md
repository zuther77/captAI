# Milestone Completion Report

**Milestone:** M7 — Reliable local region and full-screen recording
**Gate decision:** **PASS (2026-11-26).** Region and full-display ScreenCaptureKit recordings produce playable local `.mov` files with HUD controls, optional audio, library upsert, and no AI on start/stop. The product owner ran TEST_MATRIX "Manual: M7" on a real Mac: items 1–5 PASS.
**Branch:** `milestone/M7-recording`

## Implemented
- **Recording state machine:** `idle → selecting → armed → recording ↔ paused → stopping → saved/failed` (Record confirms after selection; Cancel/Esc while armed; duplicate Stop ignored while stopping).
- **ScreenCaptureKit recorder:** `SCStream` + `SCRecordingOutput` to `.mov`; HUD and region shade excluded from the stream; success only after a playable file exists.
- **RecordingCoordinator:** permission, region or entire-display target, duration cap (30 min), display-unplug abort, library video upsert, menu + shortcut toggle.
- **HUD:** after selection, Record / Cancel; Record starts capture and switches to elapsed time + Stop (Pause hidden — `SCRecordingOutput` does not support pause).
- **Region shade:** translucent outside-region dim with clear hole and border (mouse-transparent).
- **Settings:** system audio / microphone toggles; choose recordings folder.
