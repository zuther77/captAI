## Implemented
- **Providers:** named profiles for Ollama, OpenAI / compatible, Anthropic, and ChatGPT account (OSS SIWC). Active profile drives the next request only. Footer opens Settings > Providers; replies record who answered.
- **Adapters:** Ollama `/api/chat` with vision check; OpenAI chat completions + SSE; Anthropic Messages SSE; ChatGPT Responses API with plan OAuth (`store: false`, EasyInput history). Fake `HTTPTransport` for unit tests.
- **Privacy:** cloud consent (ask every time / once / local only / skip-ask toggle); Keychain secrets; workspace windows default to `sharingType = .none` with an opt-in for demos; captAI still excludes them from its own captures.
- **UX:** set-up empty state (no mock default); Stop keeps partial text; frozen capture stays on its Space and is draggable; assistant chrome is clipped `hudWindow` material (Liquid Glass rim rejected).
- **Fixes during M4:** OpenAI/ChatGPT follow-up encoding; deleted profiles resurrecting via legacy Ollama settings; ChatGPT assistant history as `input_text` 400s.
