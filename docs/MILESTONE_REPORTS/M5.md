## Implemented
- **Heuristic chips:** offline OCR → `HeuristicActionClassifier` → Explain Error / Find Fix / Copy Text / Copy Code / Analyze Chart / Find Alternatives. Copy chips never call a model; model chips send one fixed follow-up (consent still applies). Copy Code and Copy Text currently share the same OCR→clipboard path (labeling differs by heuristic).
- **Annotations:** highlight and arrow on the frozen capture via `AnnotationDocument` + `AnnotationCanvasView` (circle and rectangle dropped as redundant). Normalized top-left geometry; undo/redo/delete; hover names on toolbar icons; Select moves the capture (overlay hit-testing passes empty space to AppKit).
- **Region-aware ask:** Ask about selection crops in memory (`ImageCropper`) and sets `AnalysisRequest.imageIsAnnotationCrop`; ordinary sends keep the full PNG and append mark coordinates to the prompt. PNG on disk is never rewritten (D-031).
- **Composer:** annotation badge when marks exist.
