## Implemented
- Global screenshot shortcut (default ⌘⇧8, D-011) through Carbon `RegisterEventHotKey`; editable in Settings > Shortcuts with a key recorder, validation (modifier required, duplicates, system shortcuts) and visible error text. Moving a shortcut releases the old one (D-015).
- `CaptureCoordinator` serializes captures (idle / checking permission / selecting / capturing), debounces repeated triggers (0.4 s) and always dismisses the overlay before returning to idle.
- Per-display borderless overlay at screen-saver level: dim, clear hole, border, crosshair, W × H label (on the display under the pointer), hint; Esc cancels; dragging in all four directions; selections can span displays (D-017); minimum 6 pt; closes cleanly on display configuration change.
- Pure geometry: `SelectionGeometry`, `DisplayLayout.captureSelection` (1×/2× scale, negative origins, clipping, floor/ceil pixel alignment at the highest scale involved, one slice per display) and `SelectionStateMachine`. `ImageCompositor` places the slices into one image.
- ScreenCaptureKit still capture, one slice per display, excluding overlay windows by ID (D-014); metadata with the displays used, pixel size, scale and time; blank-image detection.
- Atomic PNG save to `~/Pictures/captAI` (D-012); menu item "Reveal Last Capture (W × H)" and a blank-capture warning.
- Permission flow: not-determined → request → "relaunch needed" alert with Open System Settings / Relaunch captAI (D-016); typed `AppError` cases for capture failure, display change and save failure.
