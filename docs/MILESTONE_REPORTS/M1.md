# Milestone Completion Report

**Milestone:** M1 — Native screenshot region selection and still capture
**Gate decision:** **NOT PASSED — awaiting the product owner's manual real-Mac test.** Code, unit and integration tests are complete and pass. The gate needs correct still images on a real Mac including an external display (TEST_MATRIX "Manual: M1"), which the agent cannot observe.
**Branch:** `milestone/M1-capture`

## Implemented
- Global screenshot shortcut (default ⌘⇧8, D-011) through Carbon `RegisterEventHotKey`; editable in Settings > Shortcuts with a key recorder, validation (modifier required, duplicates, system shortcuts) and visible error text. Moving a shortcut releases the old one (D-015).
- `CaptureCoordinator` serializes captures (idle / checking permission / selecting / capturing), debounces repeated triggers (0.4 s) and always dismisses the overlay before returning to idle.
- Per-display borderless overlay at screen-saver level: dim, clear hole, border, crosshair, W × H pill, hint; Esc cancels; dragging in all four directions; selection clamped to the starting display (D-013); minimum 6 pt; closes cleanly on display configuration change.
- Pure geometry: `SelectionGeometry`, `DisplayLayout.captureRegion` (1×/2× scale, negative origins, clipping, floor/ceil pixel alignment) and `SelectionStateMachine`.
- ScreenCaptureKit still capture excluding overlay windows by ID (D-014); metadata with display, pixel size, scale and time; blank-image detection.
- Atomic PNG save to `~/Pictures/captAI` (D-012); menu item "Reveal Last Capture (W × H)" and a blank-capture warning.
- Permission flow: not-determined → request → "relaunch needed" alert with Open System Settings / Relaunch captAI (D-016); typed `AppError` cases for capture failure, display change and save failure.
