## Implemented
- Quick Copy runs from its own global shortcut (default ⇧⌘H, D-019) or the menu item "Quick Copy Text". It reuses the M1 region selector (including selections across displays) through a capture purpose on `CaptureCoordinator`; no assistant opens. The menu item is disabled while a capture is running.
- On-device text recognition with Apple Vision (`VNRecognizeTextRequest`), Fast or Accurate per Settings > OCR. With no languages chosen, language detection is switched on: Vision does not detect the language by default, and Japanese and Chinese text came back empty until this was fixed (found during manual testing). Fast mode only reads English, French, Italian, German, Spanish and Portuguese, so other languages need Accurate.
- Reading-order layout in image pixels (`ReadingOrder`): lines grouped by vertical overlap, sorted left to right, joined with spaces or tabs across wide gaps, indentation approximated from horizontal position, duplicates in the same place dropped.
- The clipboard is written (plain text, `NSPasteboard`) only when there is text. A blank capture, no text, or a failed recognition leaves the previous contents unchanged.
- Toast feedback in a non-activating panel on the pointer's display, announced to VoiceOver: "Copying text…" with a spinner while recognition runs, then "Copied N lines", "No text found in the selection" or an error, which replaces it. Results hide after about 2 s; the progress toast hides after at most 30 s as a safeguard. Toast placement and visibility are logged (geometry only, never text) to help diagnose full-screen problems; this logging is kept for now.
- A permission problem during Quick Copy still shows the alert with Open System Settings / Relaunch / Cancel; other Quick Copy failures are toasts.
- No history entry, no media file and no provider call. The app contains no networking code yet.
